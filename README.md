# ClipBridge

**두 컴퓨터에서 평소처럼 복사하고 붙여넣으세요.** 글자, 이미지, 서식, 파일을 자동으로 공유합니다. Windows와 Mac에서 사용할 수 있습니다.

## 1. 다운로드

[실행 파일 다운로드](https://github.com/yhc1001/ClipBridge/releases/latest)에서 내 컴퓨터에 맞는 ZIP을 받으세요. 비공개 저장소이므로 GitHub 로그인이 필요합니다.

| 컴퓨터 | 받을 파일 |
|---|---|
| Windows | `ClipBridge-portable.zip` |
| Apple 칩 Mac | `ClipBridge-macOS-arm64.zip` |
| Intel Mac | `ClipBridge-macOS-intel.zip` |

Windows는 압축을 풀고 `ClipBridge.exe`를 실행합니다. Mac은 압축을 풀고 `ClipBridge.app`을 **응용 프로그램** 폴더로 옮겨 실행합니다. Python은 설치하지 않아도 됩니다.

## 2. 처음 한 번만 연결

1. 두 컴퓨터에서 ClipBridge를 실행합니다. 한쪽은 **Main**, 다른 쪽은 **상대 컴퓨터**로 선택합니다.
2. **내 IP 주소 확인**을 눌러 나온 주소를 서로의 **상대 IP 주소**에 입력합니다. 같은 Wi-Fi/LAN 또는 Tailscale로 연결되어 있어야 합니다.
3. Main에서 **연결 코드 복사** → 상대에서 **연결 코드 붙여넣기** → 양쪽에서 **저장 및 연결**을 누릅니다.
4. Main에 나타나는 연결 요청을 승인합니다. **연결됨**이 보이면 끝입니다.

이후에는 복사만 하면 상대 컴퓨터에 자동으로 들어갑니다. Windows는 **Ctrl+V**, Mac은 **⌘V**로 붙여넣으세요. 파일을 처음 받을 때는 수신을 승인합니다.

## 3. 켜두고 사용

**로그인하면 자동으로 켜기**를 체크하고 저장하세요. 컴퓨터를 껐다 켜도 로그인하면 자동 실행·재연결됩니다. 창을 닫아도 Windows 트레이 / Mac 메뉴 막대에서 계속 동작합니다.

Main을 껐다 켜고 newserver를 계속 켜두는 경우도 그대로 사용하면 됩니다. Moonlight 노트북에는 설치할 필요 없습니다.

## 잘 안 될 때

- **연결 안 됨:** 양쪽 IP와 네트워크를 확인하세요. Windows 방화벽 허용 창에서는 **사설 네트워크**를 허용합니다.
- **Mac 첫 실행 차단:** Apple 개발자 서명·공증을 하지 않은 앱입니다. 파일 출처를 확인하고 시스템 설정 → 개인정보 보호 및 보안에서 실행을 허용하세요. 클립보드/키체인 접근 요청도 허용합니다.
- **붙여넣기 안 됨:** `연결됨`을 확인하고 **다시 복사**하세요. 재연결 때 이전 내용을 자동으로 덮어쓰지 않습니다.

TLS로 암호화하여 지정한 상대와만 연결합니다. 클립보드 내용을 서버나 클라우드에 보내지 않습니다. Mac↔Windows 실제 앱별 붙여넣기와 사용자 Mac의 첫 실행은 추가 확인이 필요합니다.
