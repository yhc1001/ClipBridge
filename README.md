# ClipBridge

**Main에서 복사하고, newserver나 Mac에서 바로 붙여넣으세요.** 글자·이미지·서식·파일을 연결된 컴퓨터끼리 자동으로 공유합니다.

## 다운로드

[최신 실행 파일](https://github.com/yhc1001/ClipBridge/releases/latest)에서 내 컴퓨터에 맞는 ZIP을 받으세요. 비공개 저장소이므로 GitHub 로그인이 필요합니다.

| 컴퓨터 | 받을 파일 |
|---|---|
| Windows | `ClipBridge-portable.zip` |
| Apple 칩 Mac | `ClipBridge-macOS-arm64.zip` |
| Intel Mac | `ClipBridge-macOS-intel.zip` |

Windows는 압축을 풀고 `ClipBridge.exe`를 실행합니다. Mac(macOS 14 이상)은 `ClipBridge.app`을 **응용 프로그램**으로 옮겨 실행합니다. Python 설치는 필요 없습니다.

## 처음 한 번만 연결

1. **newserver:** 역할을 **허브**로 선택하고 **저장 및 연결**. 허브에서는 IP를 입력하지 않아도 됩니다.
2. **newserver:** **내 IP 주소 확인**으로 주소를 확인한 뒤 **연결 코드 복사**.
3. **Main 또는 Mac:** **연결 코드 붙여넣기** → **허브 IP 주소**에 위 주소 입력 → **저장 및 연결**.
4. **newserver:** 새 컴퓨터의 연결 요청을 승인하면 끝입니다.

**다른 컴퓨터도 추가하려면 2~4번을 반복하세요.** 연결 코드는 한 대를 승인할 때마다 바뀝니다. 허브 1대에 참여 컴퓨터를 최대 16대까지 등록할 수 있습니다. 모두 같은 LAN 또는 Tailscale에 있어야 합니다.

## 평소에는 복사만 하세요

어느 컴퓨터에서 복사하든 나머지에 자동으로 전달됩니다. Windows는 **Ctrl+V**, Mac은 **⌘V**로 붙여넣으세요. 파일은 받는 컴퓨터마다 승인이 필요합니다. ‘이 장치의 다음 파일도 항상 허용’을 선택할 수 있습니다.

각 컴퓨터에서 **로그인하면 자동으로 켜기**를 체크하고 저장하세요. Main을 껐다 켜도 로그인하면 자동 실행·재접속됩니다. newserver는 계속 켜 두면 됩니다. Moonlight로 newserver 화면만 보는 노트북에는 설치할 필요 없습니다.

창을 닫아도 트레이 / 메뉴 막대에서 계속 동작합니다. 허브 창에서 연결된 대수와 등록한 컴퓨터를 확인하거나 특정 컴퓨터의 접속 권한을 없앨 수 있습니다.

## 기존 버전에서 바꿀 때

**모든 컴퓨터를 v1.2 이상으로 업데이트**하세요. 기존 1:1 설정은 유지됩니다. newserver를 허브로 바꾸려면 위 1~4번으로 Main과 Mac을 다시 연결하세요. 새 실행 파일에서 자동 시작 설정도 저장하세요.

## 잘 안 될 때

- **연결 안 됨:** 참여 컴퓨터에 입력한 허브 IP와 네트워크를 확인하세요. 허브의 Windows 방화벽에서는 **사설 네트워크** 연결을 허용하세요.
- **Mac 첫 실행 차단:** 개발자 서명·공증을 하지 않은 앱입니다. 출처를 확인하고 시스템 설정 → 개인정보 보호 및 보안에서 실행을 허용하세요. 클립보드·키체인 접근 요청도 허용합니다.
- **붙여넣기 안 됨:** `연결됨`을 확인하고 다시 복사하세요. 재연결 시 이전 클립보드를 자동으로 덮어쓰지 않습니다.

통신은 TLS로 암호화하고 승인한 컴퓨터만 접속합니다. 외부 서버·텔레메트리·클라우드를 사용하지 않습니다. 허브가 꺼지면 모든 컴퓨터 사이의 공유가 중단됩니다.

자동 검사는 **허브 + 참여 컴퓨터 3대**에서 수행했습니다. 서로 다른 실물 PC·Mac의 앱별 붙여넣기는 미검증입니다. [여러 대 연결·검증 결과](docs/MULTIDEVICE.md) · [Mac](docs/MACOS.md) · [상세 지원 형식](docs/WINDOWS_DETAILS.md) · [빌드](docs/DEVELOPMENT.md)
