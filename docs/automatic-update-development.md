# 자동 업데이트 개발 상태

이 브랜치는 작업 중이다. **현재 실행 파일에는 자동 확인, 자동 설치, 재시작 기능이 연결되어 있지 않다.** 배포본이나 업데이트가 아니다.

지금까지 서명된 버전·파일 정보 검증, GitHub 고정 경로에서 크기를 제한한 다운로드, 해시 확인, 관리자 전용 서명 키 저장을 위한 기반을 추가했다. 별도의 Windows CI에서 임시 키와 제한된 사용자 토큰을 사용해 접근 제한을 시험했다. 실제 배포용 키는 아직 만들지 않았다.

완성 전에 필요한 작업:

- 배포용 서명 키를 안전하게 생성·보관하고 공개 키를 제품에 고정한다. 관리자 권한으로 실행하는 서명 도구와 서명 대상 파일은 일반 사용자가 바꿀 수 없는 신뢰된 경로에서 관리해야 한다. 현재 개발용 스크립트를 사용자 쓰기 가능 폴더에서 관리자 권한으로 실행해서는 안 된다.
- 업데이트 확인·설정·실패 상태를 프로그램에 연결하고, 공식 릴리스에 서명된 정보를 포함한다. 버전 확인을 위해 GitHub에 접속함을 알리고 끄는 방법을 제공한다.
- Windows UAC 설치형에서 기존 사용자 식별자와 연결 설정을 보존하고, 검증된 설치 파일만 관리자 권한으로 설치한다. 서비스가 교체되는 동안 앱을 안전하게 종료하고 원래 사용자 세션에서 재시작하며, 실패와 롤백을 처리한다. 파일 전송 중인 경우 설치를 미룬다.
- 일반 실행형과 Mac·Linux의 각각의 설치 위치, 권한, 안전한 교체 및 재시작 방식을 구현하고 실제 운영체제에서 확인한다.
- 첫 업데이트 지원 버전은 기존 버전에 자동 업데이트 기능이 없으므로 각 장치에 한 번 설치해야 한다. 이후 업데이트 및 자동 연결을 여러 장치에서 검증한다.

기존 v1.6.5를 덮어쓰거나 테스트 목적으로 사용자의 실행 중인 앱·서비스를 종료하지 않는다. 새 버전 배포 전에는 정상 업데이트, 손상·위조 파일, 이전 버전, 중단 및 재시도, 사용자 설정 보존을 실제 설치 환경에서 검증한다.
