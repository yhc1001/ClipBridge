# 공유할 수 있는 내용

| 종류 | Windows | macOS | Linux X11 |
|---|---|---|---|
| 글자 | Unicode | UTF-8 | UTF-8 |
| 이미지 | PNG·Bitmap·DIB·DIBV5 | PNG·TIFF | PNG·Qt 이미지 |
| 서식 | HTML·RTF | HTML·RTF | HTML·RTF |
| 파일·폴더 | 탐색기 CF_HDROP | Finder file URL | URI 목록·GNOME/KDE 복사 목록 |
| Excel 표 | 공개 텍스트·HTML·SYLK/DIF | 텍스트·HTML | 텍스트·HTML |

동시에 제공되는 지원 형식은 가능한 범위에서 함께 보존하고 이미지는 PNG/DIB로 변환합니다. 서로 다른 OS 사이에서도 **파일 내용을 전송**한 뒤 수신 컴퓨터의 로컬 파일 목록을 등록합니다. 자동 실행이나 파일 열기는 하지 않습니다.

기본 클립보드 합계는 **256MiB**(최대 512MiB), 파일은 **16GiB**(최대 1TiB·파일/폴더 20,000개)입니다. **고급 설정…**에서 조절합니다. 큰 전송에는 허브와 모든 대상 기기의 제한을 함께 높이세요. 이미지 치수는 최대 4,000만 픽셀입니다. 설정 범위의 최대 용량·개수까지 실물 전송한 결과는 아니며 실제 처리에는 메모리·디스크 공간·시간이 필요합니다.

큰 클립보드와 파일은 256KiB 단위로 전송합니다. 파일은 전체 내용을 두 번 읽어 변경과 SHA-256을 확인하므로 큰 폴더는 시작 전 확인 시간이 있습니다. 새 복사는 이전 전송을 취소합니다. 다음 항목이 오거나 종료하면 이전 수신 파일을 정리하므로 긴 파일 붙여넣기가 끝날 때까지 다음 파일을 복사하거나 앱을 종료하지 마세요.

Excel 수식·BIFF·OLE·앱 전용 비공개 형식·가상 파일/Outlook 첨부 스트림·임의 GDI 핸들은 전달하지 않습니다. 공개된 값·서식으로 붙여넣으며 원본 앱의 모든 기능 보존을 보장하지 않습니다. 지연 렌더링은 원본 앱이 데이터를 제공할 때만 읽습니다. 지원하지 않는 형식은 생략하거나 상태로 알리고 계속 실행합니다.

원격/UNC 경로·심볼릭 링크·정션·경로 이동·Windows 예약 이름·대소문자 충돌·호환되지 않는 파일명은 차단합니다. 파일 잘라내기는 복사로 바꾸며 원본을 지우지 않습니다. macOS Universal Clipboard로 수신 내용을 공유하지 않고 Windows 수신 항목에 기록/클라우드 제외 표시를 등록합니다. 원본 앱·다른 클립보드 관리자의 자체 기록은 해당 앱의 설정에 따릅니다.
