# v1.6.5 화면 배치 검증

기존 화면 배치에서는 다른 PC가 이미 있는 위치에 화면 카드를 놓으면 이동을 무시했습니다. 이제 두 카드의 위치를 서로 바꾸어 배치하고 다른 PC에도 전달합니다. 모든 화면이 가로나 세로로 이어져야 하는 기존 조건은 유지하며, 떨어지는 배치는 거부 이유를 표시하고 저장된 위치를 유지합니다. 배치 요청이 실패하면 저장된 위치를 다시 표시합니다.

로컬 회귀 검사에서 기존 버전의 자리 바꾸기 무시와 전송 실패 후 잘못된 화면 표시를 재현했습니다. 수정 후 실제 Qt 드래그 이벤트를 포함한 카드 자리 바꾸기, 잘못된 배치, 전송 실패 복구, Main과 참여 PC 각각에서 변경 후 세 장치에 TLS 배치 전파 검사가 통과했습니다. 테스트는 임시 설정·합성 UI·루프백 연결을 사용하며 사용자 PC의 클립보드나 입력 서비스를 조작하지 않았습니다. 자리 변경 후 내장 입력 엔진의 양방향 화면 링크 생성도 별도로 확인했습니다.

사용자의 실제 PC에서 새 버전을 설치하고 화면 경계를 이동해 보는 검사는 아직 하지 못했습니다. 현재 실행 중인 프로그램이나 연결은 자동으로 종료·교체하지 않았습니다.

| 플랫폼 | 자동 검사 | 빌드 |
|---|---|---|
| Windows 일반 EXE / UAC MSI | 143개 통과 / 2개 생략 | [43371163452](https://github.com/yhc1001/ClipBridge/actions/runs/43371163452) |
| Mac ARM / Intel 각각 | 130개 통과 / 9개 생략 | [43371163623](https://github.com/yhc1001/ClipBridge/actions/runs/43371163623) |
| Linux X11 | 132개 통과 / 9개 생략 | [43371163241](https://github.com/yhc1001/ClipBridge/actions/runs/43371163241) |

제품 소스는 `3c44533c3f72cf77bb8e070eda5474a51b37472c`입니다. Windows 설치형은 서비스 설치·인증·관리자 전용 테스트 화면 입력·서비스 복구·제거 검사도 통과했습니다. 실제 UAC 승인 화면이나 물리 재부팅은 미검증입니다. Mac과 Linux는 패키지 시작·종료와 내장 입력 엔진 검사도 통과했습니다. Linux 두 개의 분리된 X11 화면에서 실제 마우스·키 전달을 검사했으며, 새로 바꾼 사용자의 실물 화면 배치에서의 전환 검사는 아닙니다.
