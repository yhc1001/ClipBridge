# Windows 일반 버전과 UAC 버전

| | 일반 버전 | UAC 지원 설치형 |
|---|---|---|
| 실행 | ZIP 압축 해제 → EXE | MSI 설치 → 시작 메뉴 ClipBridge |
| 관리자 권한 | 필요 없음 | 설치·제거 때 필요 |
| 클립보드·파일 공유 | 지원 | 동일하게 지원 |
| 일반 화면 마우스·키보드 | 지원 | 지원 |
| 보안 화면 입력 | 지원하지 않음 | SYSTEM 입력 서비스 사용 |
| 자동 연결 | 사용자 로그인 후 앱 실행 | 입력 서비스는 Windows 시작 시 실행, 트레이·클립보드는 로그인 후 |

**Main과 newserver에서 UAC 화면까지 사용하려면 두 PC에 설치형을 설치하세요.** 다른 PC는 일반 버전으로도 연결할 수 있습니다. Deskflow를 따로 설치할 필요 없습니다.

## 처음 한 번

1. 기존 ClipBridge와 Deskflow는 트레이에서 종료합니다. `ClipBridge-UAC-setup-x64.msi`를 실행해 설치합니다. Windows가 설치 승인을 물으면 직접 승인하세요.
2. 시작 메뉴 **ClipBridge**를 열어 클립보드 연결을 설정하고 **로그인하면 자동으로 켜기 → 저장 및 연결**을 누릅니다. 기존 ClipBridge 연결 정보는 유지됩니다.
3. **마우스·키보드 / 화면 배치…**에서 서로 연결 코드를 등록하고 공유를 켭니다. Main은 서버, newserver는 클라이언트로 두면 됩니다. [화면 배치 방법](MOUSE_KEYBOARD.md)

설정 화면에 **UAC 지원 · Windows 서비스**, 입력 상태에 **UAC 서비스 · 마우스·키보드 연결됨**이 표시됩니다. 설치 직후 공유를 켜지 않은 상태에서는 입력 서비스만 대기합니다.

## 이후에는

newserver는 켜 두고 Main을 껐다 켜면 됩니다. 저장된 입력 설정으로 서비스가 재시도하며 Main이 돌아오면 다시 연결합니다. 클립보드는 로그인 후 ClipBridge가 실행되면 연결되고, **그다음 새로 복사한 내용**부터 공유됩니다. 이전 클립보드를 덮어쓰지 않습니다.

창의 X는 트레이로 숨기기입니다. 트레이의 **종료**는 공유를 멈춥니다. Windows 종료는 자동 연결 설정을 유지합니다. 입력 프로세스나 서비스가 비정상 종료되면 자동으로 재시도합니다. Windows UAC 보안 설정은 변경하지 않습니다.

설치형과 포터블을 동시에 실행하지 마세요. 같은 사용자로 설치형이 등록돼 있으면 포터블 GUI도 설치된 입력 서비스를 사용할 수 있습니다. 다른 마우스 공유 프로그램이 켜져 있으면 먼저 정지하세요.

## 설치·보안 범위

- Windows x64 설치형입니다. 설치한 사용자 계정에만 설정 권한을 부여합니다. 다른 계정으로 사용하려면 그 계정에서 관리자 설치가 필요합니다. RDP·빠른 사용자 전환은 미검증이며 활성 콘솔 세션 한 개를 대상으로 합니다.
- 입력 프로그램은 보호된 Program Files, 서비스 인증서는 보호된 ProgramData에 저장합니다. 등록한 상대의 TLS 인증서를 확인합니다. 클립보드·파일 내용은 입력 서비스에 저장하지 않습니다.
- 입력 서버의 방화벽은 지정한 입력 포트·설치된 입력 프로그램·사설 네트워크·LAN/Tailscale 주소 범위로 제한합니다. 공용 네트워크는 열지 않습니다. 기존 Deskflow의 서비스·방화벽 규칙은 바꾸지 않습니다.
- 제거는 Windows **설정 → 앱 → 설치된 앱 → ClipBridge (UAC)**에서 합니다. 서비스와 입력 프로세스가 종료됩니다. 사용자별 ClipBridge 연결 설정·받은 파일은 유지됩니다.
- 설치 파일은 개발자 코드 서명이 없습니다. UAC의 게시자 표시가 확인되지 않은 게시자로 나올 수 있습니다. 이 저장소의 배포 파일과 SHA-256을 확인하세요.

자동 검사는 별도 Windows CI에서 수행합니다. 실제 UAC 승인 창·Windows 로그인 화면·실물 PC 재부팅 검사는 별도 확인이 필요합니다. [검증 결과](VALIDATION-v1.5.md)
