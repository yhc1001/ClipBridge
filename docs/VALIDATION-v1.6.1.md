# v1.6.1 검증

## 수정과 재현

- 클립보드 내용의 SHA-256만 비교하던 필터가 새 복사까지 누락시켰습니다. 연결 실패 후 같은 텍스트를 재복사하거나, 같은 파일 경로의 내용을 수정하고 다시 복사할 때 Windows와 공용 macOS/Linux 작업기 모두 재현했습니다. Windows 일시 중지 중 복사한 내용을 재개 후 다시 복사해도 누락됐습니다.
- 내용 해시와 변경 시퀀스를 함께 비교하도록 수정했습니다. 새 복사는 같은 내용이라도 다시 전송하고, 같은 이벤트와 수신 출처 표시는 계속 중복/루프를 차단합니다.
- IP 승인 통합 그룹에 이전 단방향 설정이 남는 문제를 수정했습니다. 그룹 로드와 승인/재연결 시 양방향을 적용하며, 이전 수동 연결의 명시적 단방향 설정은 보존합니다.
- 기존 Deskflow가 실행 중일 때 클립보드 충돌 가능성을 알립니다. PC 승인과 실제 클립보드 연결의 상태 문구를 구분합니다. 다른 프로그램이나 실행 중인 서비스를 자동으로 제거하지 않습니다.

## 안전한 로컬 검사

사용자의 클립보드·마우스를 변경하지 않는 가짜 pasteboard, 별도 임시 설정, loopback TLS로 검사했습니다. 실제 클립보드나 전송 파일의 내용은 읽지 않았고, 인증 비밀을 출력하거나 기록하지 않았습니다.

- 수정 전 반복 복사 테스트: 6개 중 5개 실패, 1개 통과. 수정 후 전부 통과.
- 통합 승인 후 Main/newserver/Laptop 세 대 각각에서 나머지 두 대로 텍스트+HTML, 이미지, 파일+폴더의 실제 바이트 전달을 확인했습니다. 총 6방향이며 중복 되돌림과 추가 파일 승인 없이 동작합니다. 세 PC 모두 예전 단방향 설정에서 시작했습니다.
- 기존 네트워크·다중 장치·통합 승인·공용 pasteboard·용량/UI 로컬 검사 57개 통과.
- 서비스 정책·파이프·네이티브 제어·입력 번들 검사를 포함한 추가 로컬 실행은 70개 통과, 내장 엔진 `--version` 검사 1개 실패(exit 10). 기존 Deskflow가 실행 중인 작업 PC에서 발생했으며 실행 중인 서비스를 정지하지 않았습니다. 깨끗한 CI의 패키지/서비스 검증 결과를 별도로 확인합니다.

## OS별 빌드

Windows 일반 EXE/UAC MSI, macOS ARM/Intel, Linux X11의 CI 검증은 진행 중입니다. 완료 후 실행 ID와 결과를 기록합니다.

## 실제 장비 검증 범위

물리 PC 세 대에서의 최종 붙여넣기, PicPick/캡처 도구/브라우저/Word/Excel/탐색기/Finder/Moonlight, 실제 UAC 승인 창, 재부팅은 미검증입니다. 동시 실행 중인 기존 Deskflow를 사용자 대신 정지하거나 제거하지 않았습니다. 실제 환경에서 두 프로그램의 경합을 없앤 뒤 모든 PC를 같은 버전으로 업데이트하고 같은 Main에 연결해야 합니다.
