# v1.3.0 검증 결과 — 2026-10-21

Windows **83개**, Ubuntu 24.04 X11 **79개**, macOS 15 Apple 칩·Intel 각각 **77개** 자동 검사가 통과했습니다. 네 OS/아키텍처 실행 파일 모두 빌드·시작·정상 종료를 확인했습니다. OS가 다른 네이티브 테스트 모듈은 건너뜁니다.

네트워크 검사는 한 호스트의 독립 엔진·실제 TLS 소켓·실제 파일 바이트를 사용합니다. OS 클립보드는 별도 네이티브 검사이며 서로 다른 실물 OS의 앱별 붙여넣기 결과와 구분합니다.

추가로 큰 텍스트의 EXE↔네이티브 양방향 분할 전송, 큰 텍스트+파일 묶음의 4개 엔진 중계, 상대 용량 제한, 디스크 부족 거부, 암호화 키 변조, 원격 파일 URI 차단, 별도 고급 설정 창과 취소, 드래그 배치 데이터 처리를 검사했습니다.

Linux는 실제 X11 클립보드에 Unicode·HTML·RTF·로컬 파일 URI를 쓰고 읽었습니다. 별도 xclip 프로세스가 복사한 내용을 백그라운드에서 감지했습니다. GNOME/KDE MIME 변환은 검사했지만 파일 관리자 UI와 Wayland 백그라운드 동작은 미검증입니다.

설치된 Deskflow 1.27.0으로 전용 프로필 준비·공개 CLI 실행·원본 프로필 보존·임시 개인키 삭제를 확인했습니다. TLS/인증서 고정·클립보드 끄기·화면 이름/연결·보조키 설정·외부 명령 비활성화를 검사했습니다. 입력 후크는 시험 중 실행하지 않았고 기존 Deskflow는 그대로 유지했습니다. 여러 실물 OS 사이의 마우스/키보드, 잠금 화면, OS 권한 승인 UI는 미검증입니다.

최대 512MiB 클립보드·1TiB 파일·20,000개 항목은 허용 범위이며 그 최대치까지 전송/부하 테스트한 결과가 아닙니다. 실제 Mac 첫 실행 승인, Linux 배포판별 호환성도 미검증입니다.
