# 마우스·키보드

별도 연결은 없습니다. **Main IP 입력 → Main에서 승인**하면 클립보드·파일과 함께 자동으로 연결합니다. 화면 배치도 양쪽에 바로 표시합니다.

기본 화면의 **마우스·키보드 공유**만 켜거나 끄세요. 꺼도 클립보드·파일 공유는 유지됩니다. Main의 마우스가 꺼져 있으면 다른 PC의 입력 수신도 멈춥니다. 각 PC의 선택은 저장합니다.

화면 카드를 드래그하여 실제 모니터 위치처럼 놓습니다. 가로나 세로로 맞닿은 화면으로 마우스가 넘어가며, 반대쪽 가장자리로 돌아올 수 있습니다. 배치는 어느 PC에서 바꾸든 전체에 반영됩니다. Scroll Lock으로 화면 이동을 잠그거나 풀 수 있습니다.

v1.6.2부터 화면 경계에서 기다리지 않고 바로 전환합니다. 통합 연결에 남은 이전 기본 대기 250ms는 업데이트 시 한 번 해제합니다. 별도로 지정한 다른 지연 값과 이후 직접 변경한 선택은 유지합니다. 마우스 입력은 내장 Deskflow 엔진이 TLS로 직접 송수신하며, 클립보드·파일 전송은 별도 연결과 작업기로 처리합니다.

다른 마우스 공유 프로그램은 먼저 정지하세요. ClipBridge에는 입력 엔진이 포함되어 있어 Deskflow 설치는 필요 없습니다. Windows 보안 화면 입력은 [UAC 설치형](WINDOWS_UAC.md)을 사용합니다. 일반 버전은 로그인 후 일반 화면 입력을 지원합니다. Mac은 손쉬운 사용·입력 모니터링 권한이 필요할 수 있으며 Linux는 X11을 지원합니다.

‘클립보드·파일 연결됨’과 마우스 연결은 별도 상태입니다. 마우스 체크박스 아래에 **마우스·키보드 연결됨**이 표시되는지 확인하세요. **기존 Deskflow 실행 중**이면 해당 PC의 Deskflow를 서비스까지 정지하거나 제거한 뒤 마우스 공유를 껐다 켭니다.
