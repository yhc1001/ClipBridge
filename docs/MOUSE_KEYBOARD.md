# 마우스·키보드 공유

ClipBridge의 **마우스·키보드 / 화면 배치…**에서 설정합니다. 마우스·키보드가 꽂힌 컴퓨터는 **서버**, 입력을 받는 나머지는 **클라이언트**입니다. 클립보드 허브 역할과 독립적입니다. Main을 마우스 서버로, 계속 켜 두는 newserver를 클립보드 허브로 둘 수 있습니다.

1. **Main:** 역할을 **서버**로, **newserver와 나머지 PC:** **클라이언트**로 선택합니다. 클라이언트의 **마우스 서버 IP**에는 Main의 주소를 넣습니다.
2. 서로의 **이 컴퓨터 마우스 연결 코드 복사** → 상대 컴퓨터의 **상대 마우스 연결 코드 추가**로 양쪽을 등록합니다. 서버의 화면 카드를 실제 모니터 위치처럼 드래그합니다. 화면끼리 가로나 세로로 맞닿게 놓으세요.
3. 각 컴퓨터에서 **ClipBridge에서 마우스·키보드도 공유 → 저장 및 적용**을 누릅니다. 이후 화면 가장자리로 마우스를 옮기면 됩니다.

화면 가장자리로 마우스를 옮기면 다른 컴퓨터로 넘어갑니다. Scroll Lock으로 화면 이동을 잠금/해제합니다. 클립보드 코드(CB1-)와 마우스 코드(CBI1-)는 별도입니다.

- 마우스 창도 스크롤하며 저장·취소 버튼은 아래에 고정됩니다. 전환 지연·스크롤 배율·스크롤 반전·상대 좌표 이동을 설정합니다.
- 마우스 기본 포트는 **24801**입니다. 서버의 사설 네트워크 방화벽에서 이 TCP 포트를 허용하세요. 예전 ClipBridge에서 설정한 포트가 있다면 유지됩니다.
- 내장 입력 엔진의 별도 클립보드는 끄고 ClipBridge가 큰 이미지·파일을 처리합니다. TLS·인증서 고정을 사용하며 등록한 상대만 수락합니다.
- 다른 마우스 공유 프로그램을 함께 켜면 충돌할 수 있습니다. 기존 Deskflow가 실행 중이면 먼저 정지해야 합니다. 설치나 실행은 필요 없습니다.
- Main이 꺼지면 마우스는 사용할 수 없지만 newserver의 클립보드 허브는 계속 동작합니다. 로그인 자동 시작을 저장하면 다음 로그인에 마우스 엔진도 재시작하고 연결이 끊어지면 재시도합니다.
- 종료 시 자신이 실행한 마우스 엔진도 종료합니다. Windows 잠금 화면/UAC/로그인 전 입력은 지원 범위가 아닙니다. macOS는 내장 입력 엔진에 손쉬운 사용·입력 모니터링 권한이 필요할 수 있습니다. 이번 Linux 배포본의 마우스·키보드도 X11 전용입니다. Wayland 입력 엔진은 포함하지 않습니다.

일반 설정 화면에는 다른 프로그램의 설정을 가져오는 기능이 없습니다. 이미 ClipBridge에 저장한 화면 배치·인증은 그대로 사용합니다. TLS 설정·명령 비활성화·배치·프로필 보존과 Linux 가상 화면 두 개 사이의 실제 마우스·키 전송을 검사했습니다. 실물의 여러 OS 사이 마우스 이동·키보드 입력·권한 승인 UI는 미검증입니다.

자동 시작은 **사용자 로그인 후** 동작합니다. Windows는 현재 사용자의 Run 등록을 사용합니다. 일반 앱의 비정상 종료를 Windows 서비스처럼 감시·자동 복구하지 않으며, 로그인 전·잠금 화면·UAC 입력도 지원하지 않습니다. 네트워크가 끊기거나 입력 자식 프로세스가 종료되면 앱이 실행 중인 동안 재접속·재시도합니다. 실제 재부팅 후 연결은 미검증입니다.

Windows 마우스 서버에서 방화벽 때문에 연결되지 않으면, 포터블 ZIP의 `Configure-Firewall.ps1`로 한 번 허용할 수 있습니다. **관리자 PowerShell**에서 다음을 실행하고 주소와 포트는 실제 값으로 바꾸세요. Windows 방화벽 변경에는 관리자 권한이 필요합니다.

```powershell
.\Configure-Firewall.ps1 -PeerIp 192.168.0.20 -Port 24801 -InputOnly
```

이 규칙은 사설 네트워크·지정한 상대 IP·지정한 TCP 포트만 허용합니다. 입력 엔진은 매번 별도 임시 경로에서 실행하므로, 이 선택 사항에서는 실행 파일 경로 대신 포트와 상대 IP로 제한합니다. 공용 네트워크는 열지 않고 클립보드 방화벽 규칙도 바꾸지 않습니다. 상대가 여러 대면 `-PeerIp 192.168.0.20,192.168.0.21`처럼 입력합니다. 가져온 Deskflow 포트가 24800이면 `-Port 24800`을 사용하세요.
