# 마우스·키보드 공유

ClipBridge의 **마우스·키보드 / 화면 배치…**에서 설정합니다. 마우스·키보드가 꽂힌 컴퓨터는 **서버**, 입력을 받는 나머지는 **클라이언트**입니다. 클립보드 허브 역할과 독립적입니다. Main을 마우스 서버로, 계속 켜 두는 newserver를 클립보드 허브로 둘 수 있습니다.

1. 각 컴퓨터에서 **ClipBridge만 실행**합니다. 마우스 엔진은 내장되어 있습니다. 기존 Deskflow 사용자는 **기존 Deskflow 설정·화면 배치 가져오기**를 누릅니다. 처음 창을 열 때 기본 프로필이 있으면 자동으로 불러옵니다.
2. 서버에서 화면 카드를 드래그해 실제 모니터 위치처럼 놓습니다. 컴퓨터 이름은 양쪽에서 정확히 같아야 하며 화면끼리 가로나 세로로 맞닿아야 합니다. 클라이언트에는 서버 IP를 입력합니다.
3. 기존 Deskflow에서 **정지**한 뒤 **ClipBridge에서 마우스·키보드도 공유 → 저장 및 적용**을 누릅니다. 기존 인증서·신뢰 목록도 가져옵니다. 신규 컴퓨터는 서로의 **마우스 연결 코드(CBI1-)**를 복사해 양쪽에서 **상대 마우스 연결 코드 추가**로 등록합니다.

화면 가장자리로 마우스를 옮기면 다른 컴퓨터로 넘어갑니다. Scroll Lock으로 화면 이동을 잠금/해제합니다. 클립보드 코드(CB1-)와 마우스 코드(CBI1-)는 별도입니다.

- 마우스 창도 스크롤하며 저장·취소 버튼은 아래에 고정됩니다. 전환 지연·스크롤 배율·스크롤 반전·상대 좌표 이동을 설정합니다.
- 기존 이름·역할·포트·화면 배치·인증서·신뢰 목록·스크롤·전환 지연·화면별 보조키 매핑/모서리 제한을 가져옵니다. 외부 설정의 사용자 정의 링크·단축키·화면 진입/이탈 명령은 가져오지 않습니다. 원본 설정을 수정하지 않습니다.
- 마우스 기본 포트는 24801, 기존 설정을 가져오면 기존 포트입니다. 서버의 사설 네트워크 방화벽에서 이 TCP 포트를 허용하세요. 기존 Deskflow 서비스·방화벽은 자동 변경하지 않습니다.
- Deskflow의 클립보드는 끄고 ClipBridge가 큰 이미지·파일을 처리합니다. TLS·인증서 고정을 사용하며 등록한 상대만 수락합니다.
- 기존 Deskflow core가 실행 중이면 ClipBridge의 마우스 엔진 시작을 막습니다. 기존 Deskflow의 자동 시작/서비스 설정도 확인하세요.
- Main이 꺼지면 마우스는 사용할 수 없지만 newserver의 클립보드 허브는 계속 동작합니다. 로그인 자동 시작을 저장하면 다음 로그인에 마우스 엔진도 재시작하고 연결이 끊어지면 재시도합니다.
- 종료 시 자신이 실행한 마우스 엔진도 종료합니다. Windows 잠금 화면/UAC/로그인 전 입력은 지원 범위가 아닙니다. macOS는 Deskflow 엔진에 손쉬운 사용·입력 모니터링 권한이 필요할 수 있습니다. Wayland 입력은 Deskflow와 데스크톱의 portal/libei 지원에 따릅니다.

설정 변환·TLS 설정·명령 비활성화·배치·프로필 보존을 자동 검사합니다. 실제 여러 OS 사이의 마우스 이동·키보드 입력·권한 승인 UI는 미검증입니다. Deskflow를 별도로 설치할 필요가 없습니다. 설정을 가져와 저장하면 인증서도 보호된 ClipBridge 설정에 복사되므로 기존 Deskflow를 제거해도 됩니다. 기존 Deskflow 실행은 자동으로 정지/삭제하지 않습니다.
