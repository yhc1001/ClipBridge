# v1.6.0 검증 기록

통합 연결·화면 배치 변경을 구현했습니다. 로컬 격리 검사에서 실제 loopback TLS의 한 번 승인·인증서 자동 등록·공유 배치·재연결·거절·취소·인증서 위조 거부와 실제 텍스트/이미지/파일 전송을 확인했습니다. Qt의 별도 offscreen 테스트 창에서 IP 버튼 → 승인 → 연결·배치 자동 표시 및 마우스 OFF 시 클립보드 유지도 통과했습니다. 입력 엔진과 사용자 클립보드는 이 로컬 UI 검사에서 대체했습니다.

배포용 네이티브 CI 검사는 진행 중입니다. 완료 전에는 배포본 검증 완료로 해석하지 마세요. 실제 UAC 승인 창·실물 PC 재부팅·서로 다른 실물 OS 사이의 앱별 붙여넣기는 미검증입니다. 최종 결과는 CI 완료 후 이 문서에 기록합니다.
