# v1.6.4 연결 해제 검증

화면 카드를 클릭할 때 이동 처리에서 미리보기를 다시 만들어 선택이 해제되어, Main에서 상대 PC를 지정할 수 없는 문제를 수정했습니다. 같은 칸을 클릭하는 경우 이동·배치 저장을 하지 않고, 미리보기가 갱신될 때도 이름으로 선택을 유지합니다. 참여 PC에서는 '이 PC 연결 해제'로 표시합니다.

해제 메시지를 보낼 수 없어도 로컬의 연결 설정을 정리하고, Main에서 제거한 PC의 연결이 이미 끊겼더라도 나머지 PC에 변경된 배치를 전달합니다. 마우스 공유를 꺼 둔 사용자 선택을 유지합니다. 상대 PC가 꺼져 있으면 그 PC의 설정은 원격으로 바꿀 수 없으므로 다시 켠 후 해당 PC에서도 연결을 해제하세요.

수정 전 합성 UI와 루프백 TLS 테스트에서 카드 클릭 선택 소실 및 양쪽의 끊어진 소켓 오류를 재현했습니다. 수정 후 같은 검사와 마우스 공유 OFF 보존 검사 4개가 통과했습니다. 기존 연결 승인·배치·설정 검사 등을 포함한 로컬 선택 검사는 30개 통과했습니다. 사용자 PC의 실제 클립보드·입력·연결 설정은 변경하지 않았습니다.

| 플랫폼 | 결과 | 자동 빌드·실행 검증 |
|---|---|---|
| Windows 일반 EXE / UAC MSI | 137개 통과 / 2개 생략 | [41416138128](https://github.com/yhc1001/ClipBridge/actions/runs/41416138128) |
| Mac ARM / Intel 각각 | 124개 통과 / 9개 생략 | [41416138274](https://github.com/yhc1001/ClipBridge/actions/runs/41416138274) |
| Linux X11 | 126개 통과 / 9개 생략 | [41416138606](https://github.com/yhc1001/ClipBridge/actions/runs/41416138606) |

런타임 소스는 `62ee159e8b757972f4a499da700eba3ba5c410d4`입니다. Windows EXE의 시작·종료와 MSI의 서비스 설치·소유자 인증·SYSTEM/UIAccess·별도 관리자 데스크톱 입력·복구·제거 검사가 통과했습니다. 실제 UAC 승인 창이나 물리 재부팅은 검증하지 않았습니다. Mac/Linux도 각 OS에서 시작·종료와 내장 입력 엔진 검사가 통과했습니다.

사용자의 실제 세 PC에서 이 버전을 설치해 해제해 보는 검사는 아직 하지 못했습니다. 현재 설치된 프로그램은 자동 교체하거나 재시작하지 않았습니다.
