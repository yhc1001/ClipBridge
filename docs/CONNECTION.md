# 통합 연결

v1.6.0부터 한 번의 승인으로 클립보드·파일·마우스 인증과 화면 배치를 설정합니다. 다른 PC에서 Main IP를 입력하고 Main에서 허용하면 됩니다. 양쪽의 6자리 확인 번호를 비교하세요. 코드를 복사·붙여넣기할 필요는 없습니다.

Main은 연결을 받아 승인하는 중심 PC입니다. 연결할 때 클립보드 중계와 마우스 역할을 자동으로 맞춥니다. 기존에 newserver를 별도 클립보드 허브로 썼더라도 **새 통합 연결을 승인하면 Main 중심으로 두 PC의 연결을 전환**합니다. 따라서 Main이 꺼져 있으면 그 그룹의 공유도 멈춥니다. 기존 여러 PC는 모두 업데이트한 뒤 같은 Main에 연결 요청을 보내세요.

마우스 ON/OFF는 각 PC의 입력 공유 선택입니다. Main에서 끄면 다른 PC로 입력을 보내지 않고, 다른 PC에서 끄면 그 PC의 입력 수신을 멈춥니다. 어느 경우에도 클립보드·파일 연결은 유지됩니다. Main의 마우스가 꺼져 있으면 참여 PC에서 켜도 입력은 Main이 다시 켤 때 시작됩니다.

화면은 승인 시 자동으로 추가됩니다. 어느 PC에서든 카드를 옮기면 Main에서 유효성을 검사해 같은 배치를 모두에게 보냅니다. 카드들이 가로·세로로 맞닿아야 합니다. 잘못된 배치는 되돌리고, 동시에 수정하면 먼저 적용한 배치를 기준으로 다시 표시합니다. 자기 화면의 ‘이 PC’ 표시로 위치를 구별합니다. 선택 PC 연결 해제는 해당 PC의 입력과 클립보드 권한을 함께 해제합니다.

새 PC의 IP만 안다고 자동 신뢰하지 않습니다. 첫 요청은 항상 Main의 승인이 필요합니다. 이후에는 저장한 인증서와 개인키 소유 증명을 확인해 재연결합니다. 인증서가 바뀌면 연결을 해제하고 새로 승인해야 합니다. 승인 대기 중 상대가 종료되면 요청도 취소합니다.

Windows 설치형은 GUI의 TCP 24802(통합 연결), TCP 45832(클립보드)와 입력 서버의 TCP 24801 규칙을 구분해 관리합니다. 설치된 실행 파일·사설 프로필·LAN/Tailscale 범위에 제한합니다. 일반 버전은 Windows 방화벽에서 사설 네트워크 허용이 필요할 수 있습니다. 기본 연결 흐름에는 포트 설정이 없습니다. 이전 수동 사용자 지정 포트를 계속 쓸 경우 별도 방화벽 확인이 필요합니다.

v1.5 이하의 연결·인증 설정은 자동으로 지우지 않습니다. 기존 방식은 동작하지만 새 IP 승인 기능을 쓰려면 양쪽 모두 v1.6 이상이어야 합니다. 이 버전부터 기본 화면에서 연결 코드·역할·포트·좌표 입력을 제거했습니다. 자동 시작을 명시적으로 꺼 둔 기존 설정도 유지합니다.

v1.6.1부터 IP로 승인한 통합 그룹은 항상 양방향으로 공유합니다. 이전 단방향 설정이 남아 있어도 통합 그룹을 불러오거나 다시 연결할 때 양방향으로 맞춥니다. 통합 연결을 사용하지 않는 이전 수동 설정은 그대로 유지합니다. 파일 차단·일시 중지·텍스트/이미지/파일 ON/OFF 선택은 유지합니다.

간헐적으로 붙여넣기가 실패하면 먼저 기존 Deskflow 서비스가 같이 실행 중인지 확인하세요. ClipBridge는 다른 프로그램을 임의로 종료하지 않으며, 두 프로그램이 같은 클립보드를 갱신하면 덮어쓰기가 발생할 수 있습니다. 마우스만 되는 경우에는 ClipBridge의 **클립보드·파일 연결 상태**와 **마지막 동기화**를 별도로 확인하세요. Main에 세 대를 등록하면 Main의 상대 연결은 두 대입니다. 서로 다른 중심 PC에 나눠 연결한 그룹을 자동으로 합치지는 않습니다.

연결이 없던 동안의 내용을 재연결 시 자동 재생하지 않습니다. 필요한 내용을 다시 복사하세요. 같은 내용이나 같은 파일 경로라도 새 복사 이벤트이면 다시 전송합니다. 동일한 이벤트의 SHA-256과 Windows 시퀀스/macOS changeCount로 중복을 판별하고, 수신 항목의 출처 표시는 되돌림 루프를 차단합니다. 파일은 다시 복사할 때 실제 바이트를 다시 읽고 검증합니다.
