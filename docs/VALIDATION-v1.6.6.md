# v1.6.6 한영키 검증

## 관찰된 문제

사용자가 같은 Moonlight 환경에서 비교한 결과, 노트북 키보드의 한영키는 키 누름과 뗌이 모두 기록됐으나 메인 PC 키보드는 세 번 눌렀을 때 누름 신호만 기록됐다. 노트북에서 받은 신호도 세 번 모두 누름뿐이었다. 첫 번째 입력만 전환됐고 이후 두 번은 전환되지 않았다. 메인 PC에서 관측된 키는 `VK_HANGUL`의 F2 스캔 코드였다.

## 수정

Windows 입력을 보내는 쪽의 한국어 한영키 F2 신호만 각각의 완전한 키 누름·뗌으로 변환하고, 이후 뗌이 실제로 도착하면 중복 처리하지 않는다. 다른 스캔 코드의 한영키, 일반 Alt, 다른 언어의 키 및 수신 PC 쪽 입력 처리는 기존 동작을 유지한다. 이 수정은 Deskflow 1.27.0의 고정된 소스를 변경해 빌드한 Windows 내장 입력 core에 적용된다.

## 확인 범위

- 세 번의 누름만 있는 입력에서 세 쌍의 누름·뗌을 생성하고, 늦은 뗌을 중복 생성하지 않는 정책을 C++ 시험으로 확인했다. 다른 키는 기존 경로로 전달한다.
- 기존 ClipBridge 연결 및 기능과 설치형 Windows 서비스의 회귀 검사는 별도의 CI에서 진행한다.
- **수정 후 사용자의 실제 메인 PC → 노트북 Moonlight → 서버 PC 경로는 아직 시험하지 않았다.** 해당 환경에서 반복 전환과 다른 Alt 단축키가 정상인지 직접 확인해야 한다.

자동 업데이트는 이 버전에 포함되지 않는다. UAC 설치형은 기존 사용자 권한으로 MSI를 업데이트한다.
